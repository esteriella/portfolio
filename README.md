# Opeyemi Esther Agbaje — Developer Portfolio

This is my personal portfolio website built using Next.js and TypeScript, showcasing my experience, projects, and skills as a Fullstack Web Developer. It features dynamic components, animations, and integrates with tools like GitHub and Vercel for seamless deployment.

🚀 Tech Stack
Frontend: Next.js, React, TypeScript, Tailwind CSS, Framer Motion
Backend: Node.js, Express, Prisma
Database: PostgreSQL, MongoDB
Deployment: Vercel
Testing: Chai

🛠️ Getting Started
To run this project locally, follow these steps:

## Install dependencies

npm install

## Start the development server

npm run dev
Open your browser and navigate to <http://localhost:3000> to view the app.

📁 Project Structure
app/ — main routing and layout files (Next.js App Router)
components/ — reusable UI components
lib/ — utility functions
public/ — static assets
styles/ — global styles
prisma/ — Prisma schema and database configuration

📦 Features
Fully responsive design
Clean and modern UI with Tailwind CSS
Animated transitions with Framer Motion
Integrated project showcase with live links
Backend-ready architecture using Node.js and Prisma
